# UE5G_TestAssignment — Техническая документация

## Информация

**Версия движка** - 5.7.4

**Затраченное время** - ~25–28 часов

**Ассеты** - Персонаж и анимации взяты с Mixamo

## Инструкции по запуску

1. Нужный уровень "L_MainTestLevel" должен открыться сразу (если нет то откройте из папки Content/Levels/) 
2. Нажмите кнопку “Play”

## Ход разработки

Больше всего внимания в данном тестовом задании я уделила системе миссий: мне заранее хотелось сделать их легко расширяемыми - один DataAsset с возможностью добавления параметров и расширения функционала, runtime UObject на основе DataAsset, и абстрактный UObjective, который позволяет легко настроить данные для миссии в том же DataAsset и добавить другие реализации UObjective. Сами миссии и задачи имеют State: не начато, активно, закончено и провалено.

Я использовала Subsystem как общую точку взаимодействия с миссиями (получить, добавить, завершить), и очень много использовала паттерн Observer. `UMissionSubsystem` → `UMissionInstance` → `UObjective` → … дальше определяется в child-классах. UI берёт данные о миссиях через `UMissionSubsystem`, подписывается на изменения в списке и обновляет при необходимости.

Больше времени я по итогу делала миссии и UI к ним. Сначала пыталась сделать интерфейс, который будет отображать миссии даже за пределами экрана (по краям), но они упорно просто скрывались за экраном, поэтому расчёт их положения в каждый кадр того не стоил, и я просто сделала актёр-индикатор :)

Вся начальная логика (сиквенция, выдача миссии) вызывается в Level Blueprint.
## Известные проблемы

- Выполненная миссия просто удаляется и может быть выполнена повторно.
- Дочерние миссии с `TSoftObjectPtr` при подгрузке/выгрузке уровней не будут работать, если актёр ещё не загружен.
- В виджете с мини-игрой последовательный ввод сбивается при нажатии на другое поле (придётся вручную нажимать на текущую ячейку).

## Описание классов

### Player System

**`APlayerCharacter : public ACharacter`** *(Blueprint: BP_PlayerCharacter)*  
Основной класс персонажа. Отвечает за камеру, управление, а также реакцию на выполненную миссию через AnimMontage.

**`AMainPlayerController : public APlayerController`** *(Blueprint: BP_MainPlayerController)*  
Основной контроллер персонажа. Отвечает за лимиты поворотов и добавление UI на экран. Для интерактивных UI используется `void AddMiniGameToScreen(UUserWidget* MiniGameWidget)`.

---

### Mission System

**`UMissionSubsystem : public UGameInstanceSubsystem`**  
Подсистема, отвечающая за создание и контроль миссий. Миссии создаются через `StartMission(UMissionDataAsset* MissionData)`. Есть подписки на завершение миссий и окончание их вручную (`ForceCompleteMission` / `ForceFailMission`).

**`UMissionDataAsset : public UPrimaryDataAsset`**  
Дата-объект миссии, содержащий название (`MissionPublicName`), последовательные задания (массив `UObjective`) и класс индикатора для отображения на карте (`ObjectiveIndicatorClass`).

**`UMissionInstance : public UObject`**  
Runtime-объект на основе `UMissionDataAsset` (`UObjective` клонируются). Отвечает за собственный прогресс.

**`UObjective : public UObject`**  
Задача миссии, абстрактный класс, от которого наследуются конкретные варианты заданий (пойти в точку, выполнить успешную интеракцию и т.д.).

**`AObjectiveIndicator : public AActor`** *(Blueprint: BP_ObjectiveIndicator)*  
Индикатор задачи, прикрепляемый к другим Actor. Виджет, указывающий задачу на карте.

**`UMissionListWidget : public UUserWidget`** и **`UMissionEntryWidget : public UUserWidget`**  
Виджеты для отображения миссий. List содержит в себе несколько Entry, подписан на делегаты в `UMissionInstance` и обновляет данные Entry при каждом изменении миссий.

---

### Trigger

**`ACollisionTrigger : public AActor`**  
Актёр-триггер с коллизией и возможностью добавления классов, которые будут вызывать триггер (для задачи на вход в триггер).

---

### PasswordMiniGame

**`ACodeMiniGame : public AActor`** *(Blueprint: BP_CodeMiniGame)*  
Актёр, при взаимодействии вызывающий виджет `UPasswordWidget` (для задачи с интерактивной дверью и кодом).
